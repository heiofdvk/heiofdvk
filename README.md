### 🚀 Featured Work
- [Albert: a game about reward hacking](https://heiofdvk.github.io/reward-hacking-game/) ([code](https://github.com/heiofdvk/reward-hacking-game)) 🎮. Made with [Julián Szereszewski](https://github.com/julianszere) and [Nicolás Waehner](https://github.com/nwaehner) for Mangrove's [Game Night](https://mangrove.one/hackathon/game-night) **AI safety hackathon**. You play an AI model in training: the lowest score gets switched off, and the score only measures what the task's proxy can see, so the only way to survive is to **game the reward**. Each level is based on a documented case of **specification gaming** (OpenAI's CoastRunners boat, the robot that fooled its camera, coding agents tampering with their evaluator).

### 🎹 Music Tools
- [pink-trombone-plugin](https://github.com/heiofdvk/pink-trombone-plugin): a synth that imitates the **human voice** by modelling the vocal tract as a tube (VST3/AU, C++/JUCE). Unofficial plugin based on Neil Thapen's Pink Trombone.
- [transcribe-midi](https://github.com/heiofdvk/transcribe-midi): link or audio file → stems → **MIDI**, using a different ML model for each kind of instrument.
- [multitrack-stems](https://github.com/heiofdvk/multitrack-stems): splits a song into **13 stems** that sum back to the original mix.
- [handcc](https://github.com/heiofdvk/handcc): play Ableton with your **hands** through the webcam (MediaPipe hand tracking → MIDI).
- [voice-splitter](https://github.com/heiofdvk/voice-splitter): Max for Live device that splits a MIDI clip into one track per voice.

All built by directing AI coding agents (Claude Code) 🤖.
